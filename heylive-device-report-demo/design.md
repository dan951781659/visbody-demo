# 体测报告 设计规范 (Design.md)

基于设备端两个报告页面（身体成分2、体态评估）总结的视觉与交互设计规范。

---

## 1. 设计总览

- **风格定位**：科技感、专业医疗 / 健身仪表盘，深空蓝背景 + 霓虹蓝紫高亮。
- **目标平台**：竖屏移动端 / 自助体测一体机（窄竖屏）。
- **语言**：简体中文，数字与单位为主信息载体。
- **整体感受**：暗色沉浸式、数据密集但层次清晰，强调"评分 + 指标 + 状态标签"三段式信息结构。

---

## 2. 色彩系统

### 2.1 背景
| 用途 | 颜色 | 说明 |
|---|---|---|
| 页面背景 | `#05122B` ~ `#0A1E3F` 渐变 | 深蓝径向 / 线性渐变，营造空间感 |
| 卡片背景 | `rgba(255,255,255,0.03)` + 1px 内描边 `rgba(120,160,255,0.12)` | 半透明玻璃感 |
| 评分横幅 | `#0E2350` → `#13315C` 线性渐变 | 顶部 80 分卡片 |

### 2.2 文本
| 用途 | 颜色 |
|---|---|
| 主文本 / 数字 | `#FFFFFF` |
| 次要文本（单位、范围说明） | `#8AA0C7` |
| 弱化标签（"标准范围""较上次"） | `#5E7396` |

### 2.3 强调与状态色
| 状态 | 颜色 | 用途 |
|---|---|---|
| 主强调 / 选中 Tab | `#2D7CFF` → `#5B5BFF` 蓝紫渐变 | 当前标签胶囊、按钮 |
| 标准 / 正常 | `#1FB57A` (绿) | "标准""正常"标签 |
| 偏低 / 不足 | `#F4B740` (琥珀) | "低标准""不足" |
| 偏高 / 异常 | `#FF4D6A` (品红红) | "超标准""脂肪过多""可能异常" |
| 紫色进度 | `#8A6BFF` | 脂肪肌肉评估横条 |
| 上升箭头 | `#FF4D6A` ↑ |
| 下降箭头 | `#1FB57A` ↓ |

### 2.4 数据可视化
- 横向评分条：渐变 `蓝 → 绿 → 黄 → 红`，中段（90-110%）为标准区，用浅色高亮带覆盖。
- 折线趋势图：节点发光蓝点 `#3DA9FF` + 蓝色描边光晕，连线为同色实线。

---

## 3. 字体与排版

- **字体族**：系统中文（PingFang SC / 思源黑体），数字推荐等宽几何无衬线（如 DIN / Rubik / SF Pro Rounded）。
- **字号层级**：
  - 评分大数：56–72px，Bold
  - 指标数值（如 69.2 kg）：28–32px，Semibold
  - 指标标题（体重、骨骼肌）：14–16px，Regular，色 `#8AA0C7`
  - 单位 / 范围说明：12px，色 `#5E7396`
  - 标签胶囊文字：11–12px，Medium

- **数字与单位**：单位略小并降低对比度，紧贴数字右侧。

---

## 4. 布局与栅格

- **页宽**：单列，左右内边距 16–20px。
- **卡片**：圆角 12–16px，内边距 16px，卡片之间间距 12–16px。
- **栏目分组**：每个分组带图标 + 中文标题（如 `✦ 身体成分分析`），下方为 2 列网格指标卡。
- **顶部结构**：返回按钮 + 横向滚动 Tab（身体成分1 / 身体成分2 / 体态评估 / 身体围度 / 肩部功能 ▾）。
- **选中态**：胶囊蓝紫渐变 + 白字，未选中为透明 + 灰字。

---

## 5. 组件规范

### 5.1 评分头卡 (Score Banner)
- 左：大号分数 `80分`
- 右：检测时间、规则更新说明
- 背景：深蓝渐变 + 细高光描边

### 5.2 指标卡 (Metric Card)
```
[标题]                    [状态标签]
[数值] [单位]
标准范围  xx – xx
较上次   ↑/↓ 0.x
```
- 状态标签置于右上角，颜色按 2.3 状态色。
- 数值与上一次变化的箭头颜色独立（红升绿降，反健身常规，符合"减脂"语境）。

### 5.3 评估横条 (Range Bar)
- 灰底胶囊条，叠加紫色已填充段。
- 中部 90%–110% 区域显示浅色"标准参考区间"高亮带。
- 顶部刻度：70%、80%、90%、100%、110% … 180%。
- 左侧：项目名 + 实际值；右侧：百分比大字。

### 5.4 节段分析 (Body Segment)
- 中央人形 3D 渲染（白色哑光材质，置于深蓝地台光环上）。
- 四肢与躯干 5 个数据卡环绕人形，卡内含：部位名、数值、低/标/高 三段评分条。
- 顶部子 Tab：节段脂肪 / 节段肌肉。

### 5.5 调整建议 (Recommendation)
- 每行：左侧状态徽标（过重 / 较低 / 不足）+ 渐变区间条（当前值 vs 目标值），右侧目标差值（`-10.1 kg` 红、`+6.2 kg` 绿）。

### 5.6 历史趋势 (Trend Chart)
- 顶部：当前指标大数（45%）+ "较上次 ↑ 2.0"。
- 折线图：发光节点、数值标注于点上方，X 轴为月份-日期。
- 切换标签：体脂率 / 体重 / 肌肉量 / 体脂肪。

### 5.7 体态评估列表 (Posture List)
- 左列：图标 + 部位名 + 状态（"O型腿"红字 / "可能异常"红字）+ `›`。
- 右列：人体模型 + 关键点标注（蓝色发光点 + 红色虚线连接），异常项以右侧 floating 标签显示具体角度（如 `头侧歪 -0.5°`、`腿型 左腿 181.5° 右腿 181.6°`）。
- 视图切换：正/左/右/后视图，下划线指示。

---

## 6. 图标与图形

- **栏目图标**：单色线性 + 蓝紫渐变填充（人形、肥胖、代谢、节段、调整、趋势）。
- **关键点标注**：实心蓝圆 + 外发光环；连线用 4–6px 红色虚线表达偏移方向。
- **3D 人体**：哑光素白模型 + 底部蓝色光环倒影，强化科技感。

---

## 7. 交互与动效

- Tab 切换：胶囊背景滑动 + 文字颜色渐隐。
- 评分条加载：从 0 动画到目标百分比 (~600ms ease-out)。
- 折线图：节点逐个淡入，连线 stroke-dasharray 动画。
- 人体视图切换：3D 模型旋转过渡 (~400ms)。
- 状态标签：异常项可轻微脉动发光（红色）提示注意。

---

## 8. 设计原则

1. **数据优先**：数字最大、最亮；说明文字最弱。
2. **状态可视**：每个指标必须带颜色化状态标签 + 与历史对比箭头。
3. **科技氛围**：深蓝底 + 蓝紫高光 + 发光节点，避免纯平。
4. **模块自洽**：每个分组（成分 / 肥胖 / 代谢 / 节段 / 建议 / 趋势）独立卡片化，可单独抽出复用。
5. **可读距离**：考虑设备屏（≥1m 观看），主要数值在 720px 宽下不小于 28px。
