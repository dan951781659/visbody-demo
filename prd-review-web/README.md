# 需求审阅台

把语雀文档或 Markdown 需求稿变成一份可复核的评分报告：六维度、20 个检查项、100 分制，每处扣分都定位到原文行号并给出修改方向。

## 启动

```sh
cd /Users/kean/Documents/零散咨询/prd-review-web
python3 server.py
```

访问 http://127.0.0.1:8765 。无第三方 Python 依赖，仅监听本机。

也可以双击项目中的 `启动需求审阅台.command`：脚本会先检查服务是否已在运行，未运行则启动并自动打开浏览器。开机后打不开页面，通常就是服务没启动。

## 首次使用

1. **语雀授权（读取私有 / 企业空间文档）**：在「文档链接 → 语雀授权」中填入该空间的语雀 Token，点「记住到本机」。Token 保存在 `.local/yuque.json`（权限 600，已在 `.gitignore` 中），只用于向语雀读取正文，不会发送给评分模型。公开文档无需 Token。
2. **评分服务**：点右上角「评分服务设置」，填写兼容 Chat Completions 的 HTTPS 地址、模型与 API Key，先点「测试连接」确认可用，再「使用此配置」。勾选「在本机保存」会把密钥写入 `.local/ai.json`（权限 600，已在 `.gitignore` 中），之后刷新页面无需重填；不勾选则只留在页面内存。也可用环境变量 `REVIEW_API_KEY` / `REVIEW_API_BASE` / `REVIEW_MODEL` 启动进程。
3. 导入文档 → 通读正文确认完整 → 选择评分范围 → 开始审阅。审阅通常需要 30–90 秒，页面会显示进度与耗时。

## 页面能力

- **三种导入方式**：文档链接（语雀开放 API 优先，其他站点回退网页提取）、文件拖放（.md / .markdown / .txt，≤1 MB）、直接粘贴。链接支持带标题的分享文本，会自动提取 URL；`/edit` 等后缀会自动处理。
- **正文可编辑**：导入后仍是普通文本域，行号即评分引用行号，先改再评。
- **报告结构**：总分环 + 结论、维度导航（含各维度折算率）、逐维度得分条、20 个检查项（分数点、原文引用、行号、「原文已匹配 / 待人工核对」、修改建议）、已排除内容、待核验材料。
- **信息不足的维度不冒充满分**：某个维度过半检查项因缺少 Demo 或引用材料未计分时，折算率不可信，该维度显示「— 信息不足」并说明原因，同时在总分旁标注有几个维度未折算。
- **报告操作**：仅看扣分项、展开全部、维度跳转；导出 Markdown；打印或存 PDF。
- **状态可见**：本地服务、评分模型、语雀授权三项状态常驻右栏；未配置评分服务时顶部与右栏都有明确提示。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/status` | 服务版本、是否已配置评分服务、默认地址与模型、评分清单、语雀授权与 AI 密钥状态 |
| POST | `/api/fetch` | `{url, yuque_token?}` 读取正文；未传 Token 时使用本机已保存的授权 |
| POST | `/api/yuque` | `{token}` 保存到本机；`{token:""}` 清除 |
| POST | `/api/config` | `{key, base, model, remember:true}` 保存评分配置到本机；`{clear:true}` 清除 |
| POST | `/api/test` | `{base?, model?, key?}` 校验评分服务连通性，返回延迟与模型；缺省字段回退到本机保存的配置 |
| POST | `/api/review` | `{text, scope, base?, model?, key?}` 返回结构化评分 |

服务端会重新校验分值范围、维度与检查项是否与清单一致、引用行号是否命中原文，并自行汇总总分，不信任模型给出的总分。模型返回结构漂移时只会报错，不会产出错误分数。

不同网关对新旧参数的支持不一致（例如部分模型只接受 `max_completion_tokens`、`temperature` 只允许默认值），`/api/test` 与 `/api/review` 会按上游报错自动降级参数后重试，并把上游原始错误说明带回页面。

## 能力与限制

- 六维度 20 项真实 AI 评分，服务端验证分值、结构与引用；N/A 项从分母排除。
- 全文质量评分与仅 P0 预审；P0 未识别到时拒绝评分并说明。
- 不调用 AI 时不会生成模拟分数。
- 未实际打开的引用与 Demo 一律标为待核验，不因未核验扣分，也不假装已核验。
- 私有语雀、登录页与复杂动态站点可能无法抓取，应上传 Markdown。不会读取本机浏览器登录凭据。
- 不持久保存上传文档与报告；AI 密钥仅在勾选「在本机保存」时写入 `.local/ai.json`（600 权限），可随时在设置中清除。
- 服务仅绑定本机，不能用作公网多用户服务。上线前需补充认证、额度限制与更严格的网络出口策略（当前 DNS 校验仍存在重绑定风险）。
- AI 分数需人工复核；模型须支持 JSON 响应，不同提供商兼容程度可能不同。同一文档多次评分会有约 ±3 分的波动，N/A 判定也可能不同，报告结论请以人工复核为准。
