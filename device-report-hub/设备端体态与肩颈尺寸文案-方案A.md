# 设备端体态与肩颈尺寸文案（方案 A：快速看懂）

## 1. 使用说明

- 适用页面：设备端报告的「颈脊健康分析」与「肩颈尺寸测量」。
- 体态文案固定使用「评估说明 / 日常注意」两段结构。
- 体态单项两段合计控制在 60–90 个汉字，优先保留当前表现、主要可能因素和 1–2 个可执行建议。
- 肩颈尺寸统一使用「参数价值」，每项控制在 35–60 个汉字。
- 使用「可能、通常、建议、关注」等审慎表达，不将检测结果作为疾病诊断或确定性原因。
- 不使用「矫正、治疗、修复、治愈、保证改善」等医疗或效果承诺。

## 3. 肩颈尺寸用户版解释

### L1 耳宽

- 参数定义：两侧耳廓最外侧的水平距离。
- 参数价值：反映头部侧面宽度，帮助判断侧睡时耳部和头侧区域所需的接触空间，不用于单独确定枕高。

### L2 颈宽

- 参数定义：颈部最宽处的水平横向距离。
- 参数价值：帮助判断颈托区域的宽度和受力面积，使颈部获得较均匀的承托，并避免枕头延伸到肩部。

### L3 肩宽

- 参数定义：左右肩峰点之间的水平直线距离。
- 参数价值：是判断侧睡头肩间隙的重要参考；还需结合睡姿、床垫软硬和肩部实际下沉情况理解。

### L4 头背距

- 参数定义：背部后缘至后脑最突出点的水平距离。
- 参数价值：帮助判断仰睡时头窝深度，以及后脑与颈托之间的高度差，需结合上背部实际下沉情况使用。

### L5 颈深

- 参数定义：背部后缘至第七颈椎点的水平距离。
- 参数价值：帮助判断颈托凸起高度和承托曲面的深度，反映颈部需要怎样贴合，不等于整只枕头的高度。

### L6 背深

- 参数定义：背部后缘至肩峰点的水平距离。
- 参数价值：帮助理解肩背到头颈的过渡关系，以及枕头肩部避让区域，使肩背能够更自然地贴合。

### H1 头颈高

- 参数定义：头顶至第七颈椎点的垂直高度。
- 参数价值：用于判断头区和颈托区的纵向尺寸与分区位置，反映头颈比例，不能单独换算为枕高。

### H2 头背高

- 参数定义：头顶至肩峰点的垂直高度。
- 参数价值：帮助判断头、颈、肩的整体比例及枕头分区位置，最终仍需结合常用睡姿和实际体验确认。


### 复用规则

- 左右肩内收使用同一套分级模板，通过「左/右」「该侧」和具体数值替换方向。
- 正常级：说明处于常规范围，强调保持习惯，不制造健康焦虑。
- 轻度异常：说明存在一定趋势，保留 1–2 个常见可能因素和一项日常建议。
- 重度异常：说明偏离更明显，但不扩大为疾病风险，不使用确定性因果。
- 骨盆类结果不描述枕头能够直接调整骨盆，只提供坐姿、站姿、久坐管理等建议。
- 所有尺寸数据只解释参考价值，不通过单项结果直接推荐枕高或产品型号。
