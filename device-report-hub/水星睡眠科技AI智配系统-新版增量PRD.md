# 水星睡眠科技 AI 智配系统新版增量 PRD

本文以旧版水星导购报告为对比基线，以当前销售模式 Demo 为目标版本，只说明新版新增、修改或迁移的功能。正文按页面组织，同一项功能只在所属页面说明一次。

Demo 中展示的推荐高度、型号参数、产品分区映射以及“每片增加 0.5 厘米、每片 15 克”的垫片换算均为演示数据，不得直接作为量产规则。

## 报告整体框架

### 品牌 Banner 与二维码

**修改内容**

旧版报告头部替换为“水星睡眠科技 AI 智配系统”品牌 Banner，并在 Banner 右上角增加二维码。图片中的品牌名称、标题和副标题均为水星提供的固定内容，页面不得自行改写。

**展示规则**

- Banner 上下左右铺满报告容器，不保留边距，不设置圆角。
- Banner 按原始比例缩放，不拉伸、不裁切核心文案。
- 二维码放在图片预留区域内，保持正方形和足够留白，不能被压缩变形。
- 二维码资源加载失败时隐藏二维码，不显示破图，Banner 其他内容正常展示。

**点击交互**

二维码本身不承担页面点击功能，用户使用外部设备扫码后打开水星配置的目标地址。报告页面不主动申请摄像头权限，也不记录扫码用户信息。

### 页签与访问模式

**修改内容**

新版取消独立的“体态评估”页签，将相关结果迁入“AI 推荐”。销售模式新增“导购操作”，用于承接产品选择、垫片调节、试躺确认和成交记录。

**展示规则**

- 用户模式显示：AI 推荐、脊柱评估、身体成分、体围测量。
- 销售模式在上述页面之外增加“导购操作”。
- 用户模式默认进入“AI 推荐”。
- 销售模式默认进入“导购操作”。
- 页签在移动端保持单行，宽度不足时允许横向滚动。
- 用户信息、测量数据和分析结果均为只读，导购不能修改测量结果。

**点击交互**

点击页签后切换对应页面。页面切换时保留本次会话中的滚动位置；再次返回该页时回到离开前的位置。

**状态规则**

- 当前页签使用高亮状态。
- 无权限的页签不显示；用户直接访问“导购操作”时回到“AI 推荐”。
- 指定页签不存在或无法识别时，回到当前角色的默认页签。
- 报告加载失败时显示“报告加载失败，请检查网络后重试”，并提供重新加载按钮。
- 会话失效时进入登录页面；登录成功后返回原报告。

## AI 推荐

### 问卷信息

**修改内容**

旧版完整答题回顾和完成进度改为四项关键结果，减少与推荐无关的题目。页面只展示主睡姿、床垫硬度、睡眠问题和枕高偏好。

**字段规则**

- 每项只展示结果名称和一个最终答案，不展示题干、全部选项或答题进度。
- 单项未作答时显示“未填写”，不隐藏整张卡片。
- 枕高偏好可以参与产品推荐冲突的仲裁，但用户端不显示“算法输入”“仲裁”等内部说明。
- 问卷结果不能单独生成疾病、体态或枕高结论。

**状态规则**

问卷接口部分失败时，已获得的答案继续展示；缺失项显示“未填写”。问卷整体未返回时，模块显示“问卷信息暂未生成”，不影响尺寸、体态和压力结果。

### 肩颈尺寸测量

**修改内容**

耳宽、颈宽、肩宽、头背距、颈深、背深、头颈高和头背高增加用户可理解的解释。删除旧版导购话术，也不显示“如何解读”“参数价值”等额外标题。

**字段规则**

- 每张卡片展示参数编码、参数名称、测量值、单位和参数定义。
- 测量值统一保留一位小数，单位为厘米。
- 单项数据只解释其对头、颈、肩比例和枕头分区承托的参考价值，不能直接换算枕高。
- 解释正文控制在 35～60 个汉字，使用用户能快速理解的表达。

| 参数 | 参数定义 | 展开后的最终解释 |
| --- | --- | --- |
| 耳宽 | 两侧耳廓最外侧水平距离 | 反映头部侧面宽度，帮助判断侧睡时耳部和头侧区域所需的接触空间，不用于单独确定枕高。 |
| 颈宽 | 颈部最宽处的水平横向距离 | 帮助判断颈托区域的宽度和受力面积，使颈部获得较均匀的承托，并避免枕头延伸到肩部。 |
| 肩宽 | 左右肩峰点间水平直线距离 | 是判断侧睡头肩间隙的重要参考；还需结合睡姿、床垫软硬和肩部实际下沉情况理解。 |
| 头背距 | 背部后缘至后脑最突出点 | 帮助判断仰睡时头窝深度，以及后脑与颈托之间的高度差，需结合上背部实际下沉情况使用。 |
| 颈深 | 背部后缘至第七颈椎点距离 | 帮助判断颈托凸起高度和承托曲面的深度，反映颈部需要怎样贴合，不等于整只枕头的高度。 |
| 背深 | 背部后缘至肩峰点水平距离 | 帮助理解肩背到头颈的过渡关系，以及枕头肩部避让区域，使肩背能够更自然地贴合。 |
| 头颈高 | 头顶至第七颈椎点垂直高度 | 用于判断头区和颈托区的纵向尺寸与分区位置，反映头颈比例，不能单独换算为枕高。 |
| 头背高 | 头顶至肩峰点垂直高度 | 帮助判断头、颈、肩的整体比例及枕头分区位置，最终仍需结合常用睡姿和实际体验确认。 |

**点击交互**

解释正文默认隐藏。每张卡片右侧显示展开箭头，点击后只展开当前参数的解释，再次点击收起，不联动其他参数。切换页签后再次进入时恢复默认收起状态。

**按钮状态**

- 默认：箭头向下，解释隐藏。
- 展开：箭头向上，解释正文显示。
- 数据加载中：卡片显示骨架，箭头不可点击。
- 解释文案缺失：不显示箭头。

**异常处理**

- 数值缺失时显示“--”，不补零，也不拼接单位。
- 数值缺失时可以保留参数定义，但不展示解释箭头。
- 参数定义和解释均缺失时显示“该项数据暂未生成”。
- 数值单位异常时隐藏数值，等待接口修复，不在前端猜测或换算。

### 通用 7 分区推荐高度

**新增内容**

在肩颈尺寸下方增加通用 7 分区推荐高度，用于向用户展示算法生成的承托起点。该模块只表达通用区域和推荐高度，不涉及具体产品。

**字段规则**

- 展示七个分区的空间位置、分区编号和推荐高度。
- 高度为单值时保留一位小数并显示厘米；结果为范围时显示“最小值～最大值厘米”。
- 分区顺序和位置按正式算法结果返回，不由前端根据编号推断。
- 用户端不得出现产品代际、型号、垫片数、克重或产品分区映射。
- 模块辅助说明为：“分区高度用于提供承托起点，实际产品方案需结合产品结构与试躺体验确认。”

**状态规则**

- 数据加载中时显示分区图骨架。
- 全部结果缺失时显示“推荐高度暂未生成”。
- 单个分区缺失时保留该分区位置并显示“--”，不能用相邻分区数据填充。
- 正式高度计算规则未接入前，量产页面不能使用 Demo 固定高度。

### 颈脊健康分析

**修改内容**

旧版单项体态长文改为三个综合维度：头颈姿态、肩背姿态和躯干平衡。每个维度保留两项检测指标作为结果证据，只输出一套综合解释，不再分别为每项指标重复说明。

综合解释固定使用“常见原因、重点影响、建议怎么做”三段结构。“建议怎么做”同时包含睡眠承托建议和一至两项日常行动。

#### 头颈姿态

当前示例结果为颈椎前伸 6.2 厘米、颈椎侧偏右 4.9 度，综合等级为轻度异常。

| 文案部分 | 最终文案 |
| --- | --- |
| 常见原因 | 通常与长期低头、屏幕过低、习惯性前伸或单侧托腮有关；固定单侧睡姿及左右承托不均，也可能让头颈持续偏离自然位置。 |
| 重点影响 | 晨起后颈部可能僵硬、酸胀或一侧更紧，转头不够轻松；部分人还可能出现打鼾、口干或睡醒后头部沉重。 |
| 建议怎么做 | 试躺时让仰卧区托住颈弯、后脑自然落入头窝，侧卧区匹配肩宽并按偏斜方向微调左右高度；日常抬高屏幕，每45分钟活动一次，并练习收下巴与水平转头。 |

#### 肩背姿态

当前示例结果为右肩圆肩倾向 0.3 厘米、左肩正常 -1.6 厘米，综合等级为重度异常。

| 文案部分 | 最终文案 |
| --- | --- |
| 常见原因 | 通常与伏案含胸、长期单侧用鼠或提重物有关；固定侧卧且侧睡区高度不足、肩部缺少避让，也可能让左右肩背受力不均。 |
| 重点影响 | 右侧肩峰或肩胛骨内侧可能更易酸胀、牵拉，手臂上举不够轻松；侧睡时还可能出现肩部受压或频繁翻身。 |
| 建议怎么做 | 试躺时让侧卧区匹配肩宽，枕边保留肩部避让，避免肩部被顶向内扣；日常减少单侧负重，并做门框胸肌拉伸和双手背后交握扩胸。 |

#### 躯干平衡

当前示例结果为肩部左高右低 5.1 度、骨盆前移 5.4 厘米，综合等级为重度异常。

| 文案部分 | 最终文案 |
| --- | --- |
| 常见原因 | 可能与长期偏侧承重、单肩背包或久坐时臀部前滑、腰部悬空有关；站立重心靠前也可能让肩部和骨盆位置出现偏移。 |
| 重点影响 | 偏高侧颈肩可能更容易发紧，晨起下背部可能酸沉；久坐后腰部更易疲劳，也可能感觉身体左右不易同时放松。 |
| 建议怎么做 | 根据左右肩颈受力微调分区高度，使头、颈、胸自然延伸；枕头不直接作用于骨盆。日常双脚均匀承重、交替背包，坐满椅面并使用腰靠。 |

**文案规则**

- 原因使用“可能、通常、与……有关”，不能将习惯写成确定病因。
- 正常结果使用“处于常规范围”“无需过度担忧”“继续保持”等表达，不制造健康焦虑。
- 轻度异常使用“存在一定程度的……”；重度异常使用“存在明显的……”，但不能直接判断疾病。
- 影响只保留一至两个用户容易感知的信息，不写严重后果或疾病进展。
- 睡眠建议使用“承托、贴合、自然延伸、试躺微调”，不能使用“治疗、矫正、修复、治愈、保证改善、彻底解决”。
- 骨盆等枕头不直接接触的部位，必须明确枕头不直接作用于该部位。
- 用户持续疼痛、麻木或活动受限时，只建议咨询专业人员，不给出诊断。

**结果组合规则**

- 综合等级由算法返回，前端不取两项指标的最高值、平均值或自行判级。
- 两项指标均存在时生成综合文案；只有一项存在时保留维度卡，文案只引用已获得的结果。
- 同一维度一项正常、一项异常时，正文聚焦异常项，同时说明正常项处于常规范围，不能描述为双侧异常。
- 数值、方向和等级与文案冲突时隐藏解释，显示“结果解析暂不可用，请稍后重试”。
- 当前文案只覆盖 Demo 中的六项结果，其他方向和等级需接入完整分级文案库后才能量产。

**点击交互**

检测指标卡用于展示测量结果，不单独展开长文。用户点击“查看综合结构评分”后切换到脊柱评估；返回时恢复 AI 推荐原滚动位置。

**按钮状态**

脊柱评估结果存在时，“查看综合结构评分”可点击；结果未生成时按钮禁用，提示“综合结构评分暂未生成”。

### 压力分布

**修改内容**

保留仰睡、左侧睡和右侧睡三张压力图，在每张图下增加一句结果解释，帮助用户快速理解主要受力区域。

**文案规则**

- 仰睡示例：“压力集中于肩背与臀部，需增强头颈承托。”
- 左侧睡示例：“侧卧肩颈压力较高，建议分区缓冲。”
- 右侧睡示例：“右侧支撑相对均衡，保留腰臀贴合。”
- 每条不超过 30 个汉字，只描述主要受力区域和承托方向，不判断疾病。
- 正常或相对均衡的结果不制造风险。

**状态规则**

单张图片加载失败时显示图片占位和“图片加载失败，点击重试”，已生成的合法结果文字继续展示。某种睡姿没有数据时显示“本次压力结果暂不足以生成解释”，不能复用其他睡姿结论。

### 最优压力平衡分析

**修改内容**

保留正躺与侧躺的八区压力结果，统一按照头部、颈部、肩背、腰部、臀部、大腿、小腿、足部的顺序展示。

**字段规则**

- 正躺和侧躺分别使用各自的压力分析结果，不能共用同一组值。
- 数值与分区名称必须一一对应，缺失分区显示“--”。
- 页面只呈现压力分布结果，不根据该数据直接计算枕型、枕高或体态等级。

**点击交互与状态**

如页面使用正躺/侧躺切换控件，当前模式高亮；没有数据的模式禁用。切换只更新压力明细，不改变其他报告模块。

### 从本页迁出的功能

旧版 AI 推荐中的产品代际、产品型号、垫片调节、试躺确认和成交信息全部迁入“导购操作”。用户端不再出现具体产品推荐和成交操作，相关规则只在导购操作章节说明。

## 脊柱评估

### 脊柱结构异常评估

**修改内容**

新版统一使用“脊柱结构异常评估”，展示综合评分以及颈椎、胸椎、腰椎三项结构评估。页面增加提示：“基于脊柱综合评分模型，与 AI 推荐页的单项体态分析采用不同计算规则。”

AI 推荐负责解释单项体态与睡眠承托，脊柱评估负责展示综合结构评分，两者不能共用等级或互相替代。

**字段规则**

- 综合区域展示整数分、异常等级和评分说明。
- 当前 Demo 示例为 26 分、中度异常；该数值只用于页面展示验证。
- 颈椎、胸椎、腰椎分别展示分数、等级、刻度和评估详情。
- 当前 Demo 示例分别为颈椎 54 分、胸椎 19 分、腰椎 7 分。
- 所有分数、等级和风险均由算法返回，前端不得根据展示值自行计算或判级。
- 历史报告使用测量时的算法版本，不因新算法发布而重新计算。

**评分文案**

| 位置 | 文案模板 |
| --- | --- |
| 综合评分 | 本次脊柱结构综合评分为{分数}分，处于{等级}区间。评分由颈椎、胸椎和腰椎三部分测量结果综合得出，用于反映本次测量中身体姿态与参考范围的偏离程度。 |
| 颈椎评估 | 结合头前倾、头部侧偏及躯干对齐等测量结果，本次评估处于{等级}区间，提示头颈前后位置及左右平衡与参考范围{偏离程度}。 |
| 胸椎评估 | 结合左右肩部高度和躯干前后方向的位置表现，本次评估处于{等级}区间，提示肩背左右平衡及躯干位置与参考范围{偏离程度}。 |
| 腰椎评估 | 结合双腿姿态、膝关节角度及躯干前后和左右方向的位置表现，本次评估处于{等级}区间，提示腰部整体平衡与参考范围{偏离程度}。 |

**点击交互**

- 点击综合评分旁的问号展开评分说明，再次点击收起。
- 颈椎结构评估首次进入时默认展开，胸椎和腰椎默认收起。
- 三项详情可独立展开或收起，不互相联动。
- 展开详情只显示评估结果、日常建议和非诊断说明，不加入形成原因、严重后果或产品推销。

**状态规则**

- 综合分缺失时隐藏环形分数，显示“综合评分暂未生成”，已有分项继续展示。
- 单个结构分项缺失时该卡片显示“数据暂未生成”，前端不能根据其他分项重算。
- 算法返回未知等级时显示“待评估”，不能映射为正常。
- 页面加载中时折叠按钮不可点击。

**待补规则**

综合评分权重、刻度区间、异常等级阈值和评分说明必须由算法方提供正式版本。Demo 中的权重、分数和阈值不能直接带入量产。

### 疼痛潜在风险评估

**修改内容**

风险模块统一命名为“疼痛潜在风险评估”，分别展示颈椎、背部和腰部疼痛潜在风险。

**字段与文案规则**

- 每张卡片展示风险分数、低/中/高风险标签和一句简短建议。
- 风险文案使用“建议关注姿势调整”等中性表达，不使用“即将疼痛”“高危疾病”等确定性结论。
- 单项风险缺失时隐藏分数，保留模块空态，不影响其他风险卡。
- 风险评分和阈值由算法直接返回，前端不二次计算。

页面底部固定展示：“本报告仅供参考，具体方案请遵医嘱。本品不能替代药品及医疗器械，不用于疾病的诊断、治疗。”

## 身体成分

身体成分的主体能力沿用旧版。本次只调整总览样式、三组分析结构和指标定义交互。

### 身体成分总览

**修改内容**

总览集中展示体重、体脂率、身体质量指数、当前体重、目标体重、体重控制、脂肪控制、肌肉控制和基础代谢。

**字段规则**

- 数值、单位、状态和参考区间必须来自同一条测量结果。
- 单项数值缺失时显示“--”，不显示状态，也不能按零处理。
- 参考区间缺失时保留测量值，隐藏区间图，并提示“参考区间暂不可用”。
- 不在前端根据其他字段补算身体成分结果。

### 三组分析与指标定义

**修改内容**

页面按身体成分分析、肌肉脂肪分析和肥胖分析展示结果，每组增加“指标定义说明”。

**展示规则**

- 分析条统一使用低标准、正常、超标准三个区间，具体参考范围由结果数据提供。
- 指标定义只解释该指标是什么、用于什么，不生成饮食、运动或治疗方案。
- 基础代谢属于估算结果，不能表述为现场直接测得的能量消耗。

**点击交互**

每组“指标定义说明”默认收起，点击后只展开当前分析卡，再次点击收起。定义缺失时不显示展开按钮。

**按钮状态**

- 默认：显示“展开”，定义隐藏。
- 展开：显示“收起”，定义可见。
- 加载中：按钮禁用。

**异常处理**

单位异常时隐藏对应结果并记录错误，不在前端换算。单项结果失败不影响同组其他合法指标。

页面底部固定展示：“身体成分数据仅供参考，不作为医学诊断依据。”

## 体围测量

体围数据主体沿用旧版。本次统一身体模型、详细围度卡、指标定义和异常测量提示。

### 身体模型与基础数据

**修改内容**

页面顶部展示身体模型，并集中展示身高、体重和身体质量指数。三项基础数据与报告其他页面使用同一数据源。

**状态规则**

模型图片加载失败时显示占位图，不影响基础数据和详细围度。基础数据缺失时显示“--”，不根据其他页面数据临时补算。

### 详细围度与指标定义

**字段规则**

- 每张卡片展示围度名称、数值、厘米和对应示意图。
- 左右侧指标必须明确标注方向，不能交换或合并。
- 围度只用于尺寸、体型记录和趋势观察，不能直接换算枕高，也不能判断疾病。

**点击交互**

“指标定义说明”默认收起，点击后一次展开全部围度定义，再次点击收起。

**按钮状态**

- 默认显示“展开”，定义内容隐藏。
- 展开后显示“收起”。
- 定义内容未加载时按钮禁用。

**异常测量提示**

只有算法返回测量状态异常时才展示提示。通用文案为：“系统检测到您本次测量状态异常，测量结果可能存在偏差。若需获得更稳定的数据，建议穿着贴身衣物并按规范姿势重新测量。”

只有算法明确返回异常原因时才能展示具体原因，不能根据数值或图片自行推断。单项围度缺失时保留名称，数值显示“--”。

## 导购操作

导购操作是新版销售模式新增页面，集中承接旧版分散在报告中的产品选择、分区调节、试躺确认和成交记录。该页面只对导购开放，不重复展示体态、尺寸等长篇解读。

### 产品代际选择

**修改内容**

新版支持一代枕与二代枕切换，二代枕作为新建方案的默认产品。一代和二代分别保留自己的调节草稿。

**字段规则**

- 产品代际只包含一代枕和二代枕。
- 新建方案默认二代；历史方案按已保存产品回显，不能被默认值覆盖。
- 二代只有一个产品时不展示无意义的型号竞争。

**操作与交互**

点击产品代际后，产品图、分区数量、基础参数、推荐目标和方案预览同步切换。当前方案存在未保存调整时，切换前提示：“当前调整尚未保存，是否切换产品？”确认后切换，取消后保持原方案。

**按钮状态**

- 当前代际为选中状态。
- 产品参数加载期间两个代际按钮禁用。
- 当前产品参数缺失时允许切换其他代际，但不能进入调节。

### 一代型号匹配与人工改选

**修改内容**

一代枕展示 1～4 号型号及系统推荐，导购可以根据用户试躺体验人工改选。推荐选型与最终型号确认合并为一步，不再进行二次型号选择。

**字段规则**

- 推荐型号由正式产品主数据、通用 7 分区结果和问卷冲突仲裁共同产生。
- 页面只展示面向导购的推荐依据摘要，不展示公式、平均误差和内部映射过程。
- 推荐文案为：“推荐型号：{型号}。该型号可作为试躺起点，导购可根据用户实际体验改选。”
- 无法推荐时显示：“推荐型号暂未生成，请先核对测量和产品参数。”

**操作与交互**

点击其他型号后，当前型号立即更新，对应产品分区、基础高度和调节草稿同步加载。人工改选后以导购选择为当前方案，系统不能自动改回推荐型号。

**按钮状态**

- 系统推荐型号显示“推荐”标识。
- 当前型号显示选中状态。
- 型号参数未加载完成时全部型号不可点击。
- 正式推荐规则未配置时不展示伪推荐，但允许导购人工选择已有正式参数的型号。

**异常处理**

正式型号主数据或仲裁规则缺失时，页面标记“系统推荐暂不可用”。没有完整产品参数的型号保持禁用，不能进入垫片调节。

### 分区垫片调节

**修改内容**

旧版直接修改高度或展示复杂映射，新版改为导购增减垫片片数，高度和克重随正式换算表自动联动。一代显示 8 个产品分区，二代显示 11 个产品分区。

**字段规则**

- 产品分区图和热点位置以水星正式素材和映射表为准。
- 当前分区展示名称、基础高度、推荐高度、当前垫片数、调节克重和调节后高度。
- 垫片数只能输入整数，最小值和最大值由正式参数表提供。
- 当前 Demo 使用的“每片增加 0.5 厘米、每片 15 克”只是占位数据，量产不能使用。

**操作与交互**

- 点击产品图热点后切换当前分区，选中分区高亮。
- 点击减号减少一片，点击加号增加一片，调节后高度、克重和方案预览实时更新。
- 手动输入片数时只接受范围内整数；非法输入不更新方案。
- 点击“重置垫片”恢复进入当前产品或型号时的回显值，不是全部清零。
- 点击“保存设置”一次保存全部分区草稿。

**按钮状态**

- 减少到最小值后减号禁用，增加到最大值后加号禁用，并提示“已达到可调范围”。
- 参数加载中，热点、输入框、加减、重置和保存全部禁用，显示“产品参数加载中…”。
- 没有未保存修改时，“保存设置”禁用。
- 保存中按钮显示“保存中…”，所有调节控件禁用，不能重复提交。
- 保存成功提示“分区设置已保存”；保存失败提示“保存失败，请重试”，并保留草稿。

**异常处理**

- 产品分区映射缺失时禁用分区调节，提示“产品参数未配置，请联系管理员”。
- 垫片换算表缺失时不展示高度和克重，也不允许保存。
- 保存超时时保留草稿，先查询保存结果，再允许重试，避免重复方案。
- 方案已被其他终端更新时提示“方案已在其他终端更新，请刷新后重试”，不能静默覆盖。

### 定制方案预览

**修改内容**

预览表删除映射来源等内部信息，只展示基础高度、垫片数、克重和调节后高度。完整表格默认收起，减少长页干扰。

**字段规则**

分区顺序与当前产品一致，所有值与调节区实时同步。任何必需分区缺失时，预览中明确显示缺失状态，不能生成看似完整的方案。

**点击交互与按钮状态**

点击“展开方案”显示完整分区，再次点击收起。加载中或产品参数缺失时按钮禁用。产品代际或型号切换后，预览立即切换到对应方案。

### 舒适度评分与方案确认

**新增内容**

用户试躺后由导购记录 1～5 星舒适度评分，并确认最终方案。评分只记录体验，不参与前端重新计算推荐。

**字段规则**

- 星级范围为 1～5，默认未选择，不能默认 5 星。
- 最终方案保存产品代际、型号、参数版本、全部分区结果、舒适度评分和确认时间。

**操作与交互**

导购点击星级记录体验，确认全部必需分区后点击“确认试躺方案”。已确认方案只要再次修改任一分区，就回到“待重新确认”。

**按钮状态**

- 未评分时确认按钮禁用，提示“请先完成舒适度评分”。
- 产品或必需分区不完整时确认按钮禁用。
- 确认中按钮显示“确认中…”，不能重复提交。
- 成功提示“试躺方案已确认”。
- 失败提示“方案确认失败，请检查网络后重试”，保留评分和调节结果。

### 成交信息保存

**修改内容**

成交模块增加字段校验、保存状态和防重复提交。只有完成试躺方案确认后才能保存成交信息。

**字段规则**

- 商品型号从当前可售产品列表中选择，默认带入已确认方案的产品。
- 成交数量为正整数，默认 1，不能减至 0；最大值由订单服务返回。
- 成交日期默认当天，不能晚于业务允许日期。
- 添加商品后新增一行，数量默认为 1，商品型号需导购选择。

**操作与交互**

导购可以增加或减少数量、添加商品并选择成交日期。点击“保存成交信息”后先校验全部商品行，校验通过后整单提交。

**按钮状态**

- 未确认试躺方案时保存按钮禁用，提示“请先确认试躺方案”。
- 字段不完整时错误字段高亮，提示“请完善成交信息”。
- 提交中按钮显示“保存中…”，整个表单只读，不能重复提交。
- 保存成功提示“成交信息已保存”，并回显成交记录。
- 保存失败提示“保存失败，请重试”，保留已填写内容。

**异常处理**

成交记录按整单提交处理，任何商品行失败时不生成部分成功记录。网络中断、超时或服务异常时保留表单，允许导购修正或重试。
